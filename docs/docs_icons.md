# 💠 icons

1. Prepare all icons for the game
1. To optimize icons use https://bulkresizephotos.com:
    - xxxhdpi: https://bulkresizephotos.com/en?type=exact&width=256&height=256&format=png
    - xxhdpi: https://bulkresizephotos.com/en?type=exact&width=192&height=192&format=png
    - xhdpi: https://bulkresizephotos.com/en?type=exact&width=128&height=128&format=png
    - hdpi: https://bulkresizephotos.com/en?type=exact&width=96&height=96&format=png
    - mdpi: https://bulkresizephotos.com/en?type=exact&width=64&height=64&format=png
1. Unzip compressed images
1. Use https://imagecompressor.com/ to optimize icons
1. Rename folder depends on the dimensions:
    - drawable-xxxhdpi
    - drawable-xxhdpi
    - drawable-xhdpi
    - drawable-hdpi
    - drawable-mdpi
1. Move all folders to the corresponding flavor
